## 🧭 Overview

Shortcut Sprint is a small keyboard-shortcut trainer with browser and editor decks. Practice in timed rounds, add your own combinations, and keep progress locally.

## ✨ Features

- ⌨️ Practice browser, editor, and general productivity shortcuts.
- ⏱️ Play 45-second rounds and track your score.
- 🧩 Add custom shortcut prompts and combinations.
- 💾 Save custom cards and your best score in local browser storage.
- 🖥️ Switch between Windows/Linux and macOS modifier labels.

## 🎬 Demo

Start the Vite app, choose a deck and platform, then start a round. Click the practice area and press the requested shortcut. Custom cards are stored in the current browser.

## 🚀 Quick Start

```bash
npm install && npm start
```
